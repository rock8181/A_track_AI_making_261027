## 개념 (3)
- [[초기 이상신호 간과 패턴]] — 세 건 모두 '경미해 보이는 초기 신호'가 분기점 — 놓치면 불량 확산, 잡으면 선제 대응
- [[챔버 온도와 식각 속도 산포]] — 챔버 온도 상승 → 식각 속도 불균일 → 박막 두께 편차
- [[압력 불안정과 파티클 인과 사슬]] — 압력 편차 → 부산물 내벽 축적 → 파티클 → 표면 오염

## 규정 (15)
- [[챔버 온도 관리 기준]] — 설정값 ±0.5℃ 정상, ±1℃ 초과 10분 지속 시 1차 경고, 존간 편차 1.5℃ 초과 시 히터 점검
- [[온도 이상 점검 순서]] — 냉각수 유량 → 순환 펌프 → 센서 캘리브레이션 이력 → 히터 존별 출력
- [[챔버 압력 관리 기준(±3%)]] — 허용오차 ±3% (9/1 적용, 기존 ±5%), 2회 이상 초과 시 일시 정지 후 밸브·MFC 점검
- [[파티클 필터 월 1회 교체]] — 필터 막힘은 파티클 불량의 주요 원인
- [[경미한 이상 2회 반복 시 의무 보고]] — 온도·압력·진동·유량의 경미한 이상도 2회 이상이면 설비기술팀에 즉시 보고
- [[경고 알람 2시간 내 현장 확인]] — 냉각수 유량 등 경고 알람 발생 시 2시간 이내 현장 확인 의무
- [[PM 주기 변경 승인제]] — 예방정비 주기는 설비기술팀 승인 없이 변경 불가
- [[온도 트렌드 대시보드 자동 알림]] — 임계값 초과 시 자동 알림이 발생하도록 설정 유지
- [[QIR 작성·품질시스템 등록]] — 조치 및 원인 분석 결과는 QIR 양식으로 작성해 등록
- [[질소 퍼지 필터 분기 점검]] — 분기별 점검, 유량 저하 시 즉시 교체
- [[PVD 회전 베어링 분기 진동 측정]] — 기준치 초과 시 베어링 교체 검토
- [[CMP 소모품 교체주기 준수]] — 연마벨트/패드 장력·마모 점검, 연마압력 불균일은 스크래치 원인
- [[노광 챔버 습도 40~50% 유지]] — 국소 습도 상승 시 렌즈 오염 점검, 정기 클리닝
- [[파워서플라이 전압 점검]] — 정기 점검, 노후 장비는 예방 교체 검토
- [[비전 카메라 월 1회 캘리브레이션]] — 이력은 품질시스템 등록, 주기 초과 시 자동 경고
