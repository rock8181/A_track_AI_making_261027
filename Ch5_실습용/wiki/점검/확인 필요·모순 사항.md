# 확인 필요·모순 사항

위키를 만들며 발견한 항목 (원문은 수정하지 않았고 확인이 필요한 것만 기록)

1. **매뉴얼 개정일**: 개정일 2026-01-15인데 2.1항에 "2026년 9월 개정(±5%→±3%)" 문구 → 개정일 갱신 누락 가능 ([[설비운영매뉴얼 통합본(MAN-EQ-000)]])
2. **ETCH-02 점검 vs 교체 시점**: 7/15 회의는 점검 7/17 완료로 결정, 실제 펌프 교체는 7/19 → 7/17~19 경위가 문서에 없음 ([[품질회의록 2026-07-15 ETCH-02]], [[QIR-2026-0071 ETCH-02 냉각수 온도상승]])
3. **8/3 압력 편차**: QIR은 '미세', 메일은 '4%대'. 구 기준 ±5% 이내라 정상 처리 → 신 기준(±3%)이면 초과 (위키 서술은 추정) ([[챔버 압력 관리 기준(±3%)]])
4. **정민재 직함**: 회의록 '팀장' / 메일 '책임' — 호칭 차이로 보이나 확인 불가 ([[정민재]])
5. **자동 정지 인터록**: QIR-0083은 '추가 검토', 9월 이후 도입 여부 문서에 없음 ([[챔버 압력 관리 기준(±3%)]])
6. **9/1 회의 결과**: 8/18 회의의 다음 회의(9/1) 결과 문서 없음
