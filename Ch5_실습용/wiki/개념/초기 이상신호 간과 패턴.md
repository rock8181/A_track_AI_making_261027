# 초기 이상신호 간과 패턴

**공통 패턴**: 경미한 신호는 정상 범위·노이즈로 해석되기 쉽다.

- ETCH-02: 7/7 유량 알람 3회 → "센서 노이즈"로 처리 → 불량 6~9% ([[ETCH-02 냉각수 유량 저하 사건]])
- CVD-01: 8/3 압력 4%대 편차 → "허용 범위 내" → 불량 5~8% ([[CVD-01 챔버압력 편차 사건]])
- CLN-03: 9/25 유량 알람 2회 → 2시간 내 확인·선제 교체 → 불량 없음 ([[CLN-03 질소 퍼지 유량 저하 대응]])

**조직의 대응**: 2회 이상 반복 시 의무 보고 ([[경미한 이상 2회 반복 시 의무 보고]]), 경고 알람 2시간 내 확인 ([[경고 알람 2시간 내 현장 확인]]), 허용오차 강화 ([[챔버 압력 관리 기준(±3%)]]).
제안자: [[김도윤]] (8/18 회의).
