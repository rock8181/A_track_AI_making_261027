# anomaly-excel-report

공정/설비 데이터에서 이상 행을 찾아 엑셀(`.xlsx`)로 정리합니다. 판정은 `scripts/anomaly_report.py`가 하고, Claude는 컬럼을 확인하고 설정을 맞춘 뒤 결과를 검증·보고합니다.

## 이상 기준 (기본값, 하나라도 해당하면 이상)

1. 불량률 ≥ `RATE_LIMIT` (3.0)
2. 평균값이 정상범위(`하한~상한`)를 벗어남
3. 최대값 > 상한 + (상한−하한)×`EXCURSION_RATIO` 또는 최소값 < 하한 − (상한−하한)×`EXCURSION_RATIO` (0.6)

사용자가 다른 기준값을 말하면 그 값을 씁니다. 기준식 자체가 다르면 스크립트를 고치기 전에 먼저 확인받습니다.

## 진행 순서

1. **환경 확인**: `python --version` (없으면 `python3`, Windows는 `py`도 시도). `python -c "import pandas, openpyxl"`가 실패하면 사용자 동의를 받은 뒤 `python -m pip install pandas openpyxl`을 실행합니다.
2. **스크립트 복사**: `scripts/anomaly_report.py`를 결과 엑셀을 저장할 폴더로 복사합니다. 결과물과 스크립트를 같은 폴더에 두어 나중에 다시 실행할 수 있게 하기 위해서입니다. 파일명은 상황에 맞게 바꿔도 됩니다 (예: `find_anomaly.py`).
3. **컬럼 확인**: 그 폴더에서 `python anomaly_report.py --inputs <파일들> --inspect`를 실행해 파일별 컬럼명, 인코딩, 샘플을 봅니다.
4. **설정 맞추기**: 복사한 스크립트 상단의 `CONFIG`를 실제 데이터에 맞게 수정합니다. 이렇게 해 두면 이후 인자 없이 `python anomaly_report.py`만으로 같은 결과가 나옵니다.
   - `inputs`: 입력 파일 경로 (작업 폴더 기준 상대경로). 파일이 2개 이상이면 `key`로 결합합니다.
   - `rate_col` / `mean_col` / `max_col` / `min_col`: 불량률, 평균, 최대, 최소 컬럼명
   - 정상범위: `"하한~상한"` 형식 한 컬럼이면 `range_col`, 하한과 상한이 따로 있으면 `lower_col`/`upper_col`
   - `date_col`: 날짜 컬럼 (월별추이 시트용), `group_cols`: 집계 시트를 만들 컬럼 묶음
   - 해당 컬럼이 없는 기준은 자동으로 생략되고, 생략 사실이 콘솔과 요약 시트에 표시됩니다.
5. **실행**: `python anomaly_report.py`. 출력되는 `[주의]` 메시지(키 불일치, 정상범위 형식 오류, 생략된 기준)는 빠짐없이 사용자에게 전달합니다.
6. **검증**: 결과 엑셀을 pandas로 다시 읽어 시트별 행 수와 기준별 건수를 확인하고, 이상 행 몇 개는 원본과 대조합니다.
7. **보고**: 기준별 건수, 이상 비율, 눈에 띄는 패턴(특정 설비나 기간에 몰리는지 등), 그리고 엑셀과 스크립트의 **전체 절대경로**를 알려줍니다.

## 결과 엑셀 구성

- **요약**: 기준별 건수, 전체 대비 이상 비율, 사용한 기준값, 원천 파일
- **이상데이터**: 이상 행 전체, 걸린 기준(●), 해당 기준 수, 이상사유. 기준을 넘은 값의 셀은 빨간색입니다.
- **<그룹>별**: `group_cols`별 전체·기준별·이상 건수와 비율
- **월별추이**: `date_col`이 있을 때 생성

## 운영환경 주의사항

- 인코딩은 `utf-8-sig → cp949 → euc-kr → latin-1` 순서로 자동 판별하고, 구분자(쉼표/탭/세미콜론)도 자동 판별합니다. `.xlsx`, `.xls` 입력도 됩니다.
- Windows 콘솔에서 한글이 깨지면, 결과를 파일로 저장해 Read 도구로 읽거나 `PYTHONIOENCODING=utf-8`을 설정합니다. 스크립트 자체는 stdout을 UTF-8로 바꿔 출력합니다.
- 결과 파일이 엑셀에서 열려 있으면 저장에 실패합니다. 이때는 오류 메시지를 사용자에게 알리고, 파일을 닫은 뒤 다시 실행합니다.
- 상대경로는 실행한 폴더 기준입니다. 반드시 스크립트를 둔 폴더에서 실행합니다.
- 정상범위는 `450~460`, `-5~5`, `0.6-1.2` 같은 형식을 읽습니다. 읽지 못한 행은 기준 2)와 3)에서 빠지고 경고가 나옵니다.
- 입력 데이터에 개인정보(검사자 이름 등)가 있으면, 결과를 외부에 공유하기 전에 사용자에게 알립니다.
