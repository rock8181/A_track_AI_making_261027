# k-skill 스킬 카탈로그

- 기준일: 2026-10-27
- 출처: 이 세션의 시스템 프롬프트 스킬 목록(k-skill 계열). 원본 저장소는 GitHub `NomaDamas/k-skill` ("한국인을 위한 스킬 모음집", Stars 2k, Forks 131, Issues 12, Contributors 3).
- 목록에 없는 스킬은 포함하지 않았다.
- 설명이 목록에 없는 스킬은 이름으로 용도를 추정했고 `(이름 기준)`으로 표시했다. 실제 동작은 각 스킬의 SKILL.md로 확인해야 한다.

## 범례

| 항목 | 의미 |
|---|---|
| API키/프록시 | `불필요` 설명상 키 없이 동작 명시, `프록시` k-skill-proxy 경유 명시, `키 필요` 환경변수·인증키 명시, `확인 필요` 설명에 근거 없음 |
| 조회전용 | `예` 조회·검색만 기술, `부분` 조회 후 찜·문의·예약 등 후속 액션 가능, `아니오` 예약·발급·제출 등 실행 중심, `해당 없음` 텍스트 처리 도구, `확인 필요` 설명 없음 |
