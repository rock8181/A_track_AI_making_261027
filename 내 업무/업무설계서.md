# 업무 설계서

## 1. 자동화할 업무
- 업무명: 운영 시스템 VOC 처리

## 2. 입력 자료

| 자료 이름 | 형식 | 주요 내용 |
|---|---|---|
| VOC 접수 티켓 | VOC 시스템 게시판/티켓 | 처리할 VOC의 제목, 내용, 요청자, 접수일 |
| 시스템 DB | DB 조회 | 사용자/계정 정보, 처리·거래 이력, 에러/시스템 로그, 기준정보/코드 |
| 운영 매뉴얼 | 위키/컨플루언스 페이지 | 시스템 기능 설명, VOC 유형별 처리 절차 |
| 과거 VOC 처리 이력 | VOC 시스템 (처리 완료 티켓) | 과거 VOC의 문의 내용, 원인, 조치, 답변 |
| 처리 노하우 문서 | 텍스트 (새로 작성) | 문서화되지 않은 판단 기준과 처리 요령 |

## 3. 결과물

- 결과물 형태: VOC 처리 검토 보고서
- 구성:
  - 상단 요약: 오늘 VOC 현황(전체·처리 유형별·우선순위별 건수), 먼저 볼 건, 내가 할 조치 / 이관 목록
  - 티켓별 카드: 처리 유형·우선순위 (요청자 카테고리와 다르면 표시)
  - 티켓별 카드: 확인 근거 (DB/로그)
  - 티켓별 카드: 원인·조치 방안
  - 티켓별 카드: 이관·주의사항 (이관 여부, 본인 확인 필요, 중복·병합 등)
  - 티켓별 카드: 답변 초안 (바로 복사 가능)

## 4. 세부 업무 단계

| 단계 | Task | 실행 주체 |
|---|---|---|
| 1 | VOC 티켓 불러오기 및 요청자 정보(부서·역할·계정 상태) 조회 | 코드 |
| 2 | 문의 내용 분석 및 처리 유형·우선순위 재분류 | AI |
| 3 | 관련 시스템 로그·DB 조회 (에러 로그, 처리 이력, 기준정보) | 코드 |
| 4 | 원인 분석 및 조치·이관 방안 판단 (매뉴얼·과거 처리 이력·노하우 대조) | AI |
| 5 | 답변 초안 작성 | AI |
| 6 | VOC 처리 검토 보고서 생성 (요약 집계·티켓별 카드 배치) | 코드 |
| 7 | 보고서 검토 및 답변 확정 | 사람 |
