# 보고서 (A4 문서)

템플릿: `assets/doc-template.html` — A4 세로 3쪽, 인쇄(PDF 저장) 가능.

## 페이지 골격 (모든 쪽 공통)

- `<section class="page">` 한 개 = A4 한 장 (`210mm × 297mm`, 여백 `18mm 20mm 14mm`). 넘치면 새 `section.page`를 추가한다. 한 쪽 안에서 내용이 잘리면 안 된다.
- 본문 `10.5pt`, 줄간격 `1.62`, 색 `#1B1F2A`
- **머리말**: 좌 `대외비 · 사내 한정`(보안 등급) / 우 작성 부서 — `8.5pt #6E7688`, 아래 `0.75pt #C8CCD8` 선
- **꼬리말**: 좌 `문서번호 OOO-YYYY-MMDD` / 우 `- n -` 쪽번호 — `margin-top: auto`로 하단 고정

## 1쪽 상단

1. **제목**: 가운데 정렬, `17pt 700 #0A1547`. 한 줄(최대 두 줄), "~결과 및 ~계획"처럼 내용+목적이 드러나게.
2. **메타 줄**: `작성일 / 부서 성명 직급 / 보고대상 OOO` — `10pt #4A5568`
3. **요약 박스**(필수): `#F2F3F7` 배경 + `0.75pt #D5D9E3` 테두리. 3문장 이내로 **결론 → 근거 수치 → 미달·과제 → 대응** 순서.

## 본문 구성 (표준 순서)

장 제목은 로마 숫자 `Ⅰ. Ⅱ. Ⅲ.` + 명사형, `12.5pt 700 #0A1547`, 바로 아래 `1.2pt #0A1547` 상단선.
보고 성격에 맞지 않는 장은 빼도 되지만 **순서는 바꾸지 않는다**.

| 장 | 내용 | 주로 쓰는 블록 |
|---|---|---|
| Ⅰ. 추진 개요 | 목적·대상·기간 한 문단 + 운영 방식/경과 | 도입 문단, ○ 항목 |
| Ⅱ. 운영 현황 | 핵심 실적 | 막대 차트 + 목표 대비 실적 표 |
| Ⅲ. 성과 분석 | 발견 사실 3개 | ○ **키워드** · 설명, 상세 표 |
| Ⅳ. 문제점 | 문제 3개 이내 | ○ **키워드** · 현상과 원인 |
| Ⅴ. 개선 방안 | 과제 | 표: 과제 / 세부 내용 / 담당 / 기한 |
| Ⅵ. 향후 일정 | 월별 일정 | 좌 `월` 굵게, 우 내용 |
| Ⅶ. 건의 사항 | 의사결정 요청 한 문단 | 문단 |
| 붙임 | 첨부 목록 | `붙임  1. ○○ 1부  2. ○○ 1부` |
| 결재란 | 구분 / 담당 / 검토 / 승인 | 표 (마지막 쪽) |

## 블록 규칙

- **장 도입 문단**: 각 장은 그 장의 결론 한 문장으로 시작한다.
- **○ 항목**: `grid-template-columns: 13pt 1fr`, 기호 `○` 색 `#1428A0`. 분석·문제 항목은 `<span style="font-weight:700">키워드</span> · 설명` 형식.
- **그림·표 제목**: `〈월별 활성 사용자 추이 (천 명)〉` — 홑화살괄호, 단위 괄호, `9.5pt 700 #0A1547`
- **표**: `border-collapse`, 선 `0.75pt #C8CCD8`, 셀 여백 `5pt 7~8pt`, 글씨 `9.5pt`
  - 머리 스타일 A(요약표): `#F2F3F7` 배경 + navy 글씨
  - 머리 스타일 B(상세표, 문서당 1~2개): `#0A1547` 배경 + 흰 글씨
  - 숫자 열은 오른쪽 정렬, 핵심 열은 굵게, 달성/미달은 blue/`#B0472F`
- **차트**: CSS grid 막대(높이 %로 표현), 높이 약 `96pt`, x축 라벨 `8.5pt #6E7688`. 계열 하나.
- **주석**: 표·차트 아래 `※ ...` `8.5pt #6E7688` (출처·측정 기준)

## 문장 규칙

- 문단·항목 모두 "~하였습니다 / ~입니다 / ~필요합니다" 합쇼체로 통일한다. 반말·명사 종결 혼용 금지.
- 한 문장에 하나의 사실. 판단에는 근거 수치를 붙인다 (예: "32%p 차이가 발생하여 ~로 판단됩니다").
- 문제점은 "현상 + 원인", 개선 방안은 "담당 + 기한"이 반드시 있다.
- 쪽수는 2~3쪽이 기본. 내용이 많으면 붙임으로 돌린다.
