# 발표자료 (슬라이드)

템플릿: `assets/slide-template.html` — 1920×1080 장표를 세로로 나열, 화면 폭에 맞춰 자동 축소(`fitDeck` 스크립트 유지).

## 장표 골격 (모든 장 공통)

```html
<section data-label="장표 이름" data-screen-label="03" data-speaker-notes="발표자 메모"
  style="background: ...; padding: 110px 120px 90px; display: grid; grid-template-rows: auto 1fr auto; gap: 52px; ...">
  <!-- 1행: 장 번호(30px Gothic A1 700 blue) + 제목(h2 64px Gothic A1 700) -->
  <!-- 2행: 본문 -->
  <!-- 3행: ※ 주석 / 출처 (24px #7D8493) -->
</section>
```

- `data-label`, `data-screen-label`(01부터 두 자리), `data-speaker-notes`(발표 멘트 1~2문장)는 모든 장에 필수.
- 배경은 `#FFFFFF` → `#F2F3F7` → `#0A1547`를 번갈아 써서 단조롭지 않게 한다. 표지·성과 지표·인용·요약은 navy.
- navy 장에서는 장 번호 `#7C9BFF`, 제목 `#FFFFFF`, 본문 `#E8EBFA`/`#AEB8DE`.
- 최소 글자 크기 24px(주석), 본문 28~38px. 이보다 작게 쓰지 않는다.

## 장표 유형 (템플릿에 있는 11종만 사용)

| 유형 | 언제 | 규칙 |
|---|---|---|
| 표지 | 첫 장 | 제목 한 줄(104px, 필요 시 두 줄), 부제에 범위·대상, 하단에 구분·날짜 |
| 목차 | 5장 이상일 때 | 항목 5개 이내, 명사형. 이후 각 장 제목과 문구 일치 |
| 핵심 메시지 | 결론 제시 | 좌측 주장 한 문장(52px) + 우측 근거 숫자 3개(78px). 숫자 출처 필수 |
| 비교 표 | 기준·옵션 비교 | 열 4개·행 4개 이내, 강조 열 하나만 `#1428A0` 머리 + `#EDF0FB` 셀 |
| 프로세스·차트 | 절차와 효과 | 좌 4단계(마지막 단계만 navy), 우 막대 차트 계열 하나, 값은 막대 위 |
| 성과 지표 | 실적 | 좌 대표 지표 3개(88px), 우 가로 막대. 색은 두 가지 이내 |
| 개선 전후 | Before/After | 좌우 항목 수·어순 동일, 개선 후만 navy, 화살표 하나 |
| 이미지 중심 | 화면·사진 | 이미지 비율 유지, 설명 3줄 이내, 출처 표기. 이미지가 없으면 점선 자리 표시 유지 |
| 인용 | 현장 목소리 | 한 장에 한 인용, 원문 그대로, 화자·소속·시점 표기 |
| 일정 | 로드맵 | 마일스톤 4개 이내, 완료 구간만 진한 색 |
| 요약 | 마지막 장 | 앞 장의 결론 3줄 회수 + 다음 행동 박스 한 개. 새 정보 금지 |

## 구성 원칙

- 한 장에 메시지 하나. 제목은 내용을 요약한 문장형 또는 명사형으로 통일한다(덱 안에서 혼용 금지).
- 기본 흐름: 표지 → (목차) → 핵심 메시지 → 근거 장표들 → 요약. 결론을 먼저 보여 준다.
- 장 번호는 목차 다음 장부터 01, 02 … 순서로 매기고, 목차 번호와 맞춘다.
- 문장은 개조식 명사형(예: "주당 인당 절감 시간")으로 짧게. 한 덩어리 3줄 이내.
- 장 수는 요청이 없으면 6~11장.
