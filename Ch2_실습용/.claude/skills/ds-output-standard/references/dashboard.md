# 대시보드

템플릿: `assets/dashboard-template.html` — 한 화면(데스크톱 폭) 경영 대시보드.

## 화면 구성 (위 → 아래 순서 고정)

1. **헤더** (`#0A1547` 배경, 여백 `26px 44px 30px`)
   - 상단 eyebrow: `SAMSUNG ELECTRONICS · 부서명` (11px, 자간 0.22em, `#7C9BFF`)
   - 제목 h1: 32px Gothic A1 700 흰색
   - 기준 시점: `2026년 8월 마감 기준 · 데이터 갱신 8월 31일 06:00` (13px `#98A3D2`) — **필수**
   - 우측: 기간 토글(주간/월간/분기/누적, 선택값 `#1428A0`), 내보내기 버튼
   - 하단 헤드라인 지표 줄: 3~4개, `라벨 · 값 · 증감/목표` (위험 증감은 `#E29A80`)
2. **KPI 카드 줄**: `repeat(4~5, 1fr)`. 카드마다 라벨(13px) → 큰 숫자(34px Gothic A1 900) + 증감(12px) → 미니 차트(스파크라인 / 도넛 / 미니 막대 중 하나)
3. **주 차트 줄**: `1.9fr 1fr` — 좌 추이 차트(실적 + 목표 점선), 우 구성 도넛 + 범례
4. **분석 줄**: `1.35fr 1fr 1fr` — 구성 추이(100% 누적 막대) / 상위 항목 가로 막대 / **navy 분석 요약 카드**(발견 3개 + 다음 조치)
5. **상세 줄**: `1.9fr 1fr` — 상세 표(인라인 막대 포함) / 점검 필요 목록 + 목표 진척 바

데이터가 부족하면 줄 단위로 빼되 **헤더, KPI 줄, 분석 요약 카드는 항상 유지**한다.

## 카드 규칙

- 흰 카드: `background #FFFFFF; border 1px solid #E1E4EC; border-radius 12px; padding 20~28px`, 줄 간격 `gap 18px`
- 카드 머리: 제목 16px 700 + 부제(단위·기간) 13px `#6E7688` — **부제 필수**
- 차트 카드 하단 인사이트: `border-top 1px solid #EEF0F5` 아래 13px `#4A5568` 한두 문장 (숫자로 해석)
- 분석 요약 카드: navy 배경, 번호 `01 02 03`(`#7C9BFF`), 제목 14px 흰색 + 설명 12px `#AEB8DE`, 맨 아래 `다음 조치` 박스(`rgba(124,155,255,0.14)`)
- 점검 필요 목록: 점 색으로 심각도 표시 — 위험 `#B0472F`, 주의 `#C98A2E`, 일반 `#1428A0`. 각 항목에 부서·날짜·조치 상태

## 차트 구현

- 라이브러리 없이 inline SVG(`polyline`, `path`) 또는 CSS(`conic-gradient` 도넛, flex/grid 막대)로 그린다.
- 축 라벨 11px `#8B92A2`, 격자선 `#F1F2F7`, 기준선 `#DCE0E9`
- 추이: 실적 `#1428A0` 3px 실선 + 연한 면 그라데이션, 목표 `#98A3D2` 점선
- 구성: 데이터 계열 순서(`#1428A0 → #4B5CC0 → #7C9BFF → #C2C8E8 → #DCE0E9`)로 큰 값부터
- 표 안 막대: 6px 트랙 `#F1F2F7`, 목표 미달 행만 `#B0472F`
- 값은 입력 데이터로 좌표·퍼센트를 계산해 넣는다. 모양만 그럴듯하게 그리지 않는다.

## 문장 규칙

- 라벨은 명사형으로 짧게("월 절감 시간"). 인사이트·분석 요약은 "~입니다/~필요" 체로 수치 근거와 함께.
- 증감은 비교 기준을 명시(전월 대비, 목표 대비).
- 수집 실패·데이터 없음 영역은 카드를 지우지 말고 "수집 실패" / "데이터 없음"을 `#8B92A2`로 표시한다.
