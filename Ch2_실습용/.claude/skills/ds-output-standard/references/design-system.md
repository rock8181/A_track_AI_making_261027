# 공통 디자인 시스템

세 가지 결과물(보고서·발표자료·대시보드)이 같은 팀 문서로 보이도록 하는 공통 규칙이다.
값은 `assets/*-template.html`에서 추출한 것이며, 템플릿과 이 문서가 다르면 템플릿을 따른다.

## 서체

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Gothic+A1:wght@500;700;900&family=Noto+Sans+KR:wght@300;400;500;700&display=swap" rel="stylesheet">
```

| 용도 | 서체 | 굵기 |
|---|---|---|
| 본문, 표, 설명 | `"Noto Sans KR", "Malgun Gothic", sans-serif` | 300 / 400 / 500 / 700 |
| 큰 제목, 장 번호, 핵심 숫자(KPI) | `'Gothic A1', sans-serif` | 700 / 900 |

- 보고서는 Gothic A1을 쓰지 않는다(본문 서체로 통일). 발표자료·대시보드의 제목과 숫자에만 Gothic A1을 쓴다.

## 색상 팔레트

### 기본색
| 토큰 | 값 | 용도 |
|---|---|---|
| navy | `#0A1547` | 제목, 헤더 배경, 강조 카드 배경, 표 머리 |
| blue | `#1428A0` | 주 강조색, 링크, 양(+) 증감, 대표 막대 |
| blue-light | `#7C9BFF` | 어두운 배경 위 강조, 보조 계열 |
| white | `#FFFFFF` | 카드·페이지 배경 |

### 데이터 계열 (진한 순 → 연한 순, 이 순서로만 사용)
`#1428A0` → `#4B5CC0` → `#7C9BFF` (또는 `#909BD6`) → `#C2C8E8` → `#DCE0E9`

- 시계열 막대는 과거를 연하게, 최근을 진하게 칠한다 (`#C2C8E8` → `#909BD6` → `#4B5CC0` → `#1428A0`).
- 비교 대상 중 강조할 하나만 진하게, 나머지는 연하게.
- 목표선: `#98A3D2` 점선(`stroke-dasharray="8 7"`).

### 상태색
| 의미 | 밝은 배경 | 어두운 배경 |
|---|---|---|
| 양호·증가(+) | `#1428A0` | `#7C9BFF` |
| 미달·감소(−)·위험 | `#B0472F` | `#E29A80` |
| 주의 | `#C98A2E` | — |

- 빨강/주황은 "문제"를 표시할 때만 쓴다. 장식용으로 쓰지 않는다.

### 텍스트 (밝은 배경)
`#1B1F2A`(보고서 본문) · `#0A1547`(제목) · `#2D3A52`(본문 강) · `#4A5568`(본문 약·해설) · `#5A6478` · `#6E7688`(캡션·단위) · `#7D8493` · `#8B92A2`(축 라벨)

### 텍스트 (navy 배경)
`#FFFFFF` · `#E8EBFA` · `#CFD6F0` · `#AEB8DE` · `#98A3D2` · `#8590BC`

### 선·면
- 선: `#C8CCD8`(보고서 표·구분선) · `#D5D9E3` · `#DCE0E9` · `#E1E4EC`(카드 테두리) · `#EEF0F5` · `#F1F2F7`(막대 트랙)
- 면: `#F2F3F7`(연한 패널·표 머리) · `#EDF0FB`(강조 열) · `#E4E7EF` / `#B4BAC9`(이미지 자리)
- 화면 배경: 보고서 `#E9EBF0`, 발표 `#05091F`, 대시보드 `#EEF0F5`
- navy 위 구분선: `rgba(200,210,240,0.28)` / 반투명 강조 면: `rgba(124,155,255,0.14)`

## 공통 표기 규칙

- 날짜: 보고서 `2026. 08. 31.` / 발표·대시보드 `2026. 09.`, `2026년 8월 마감 기준`
- 숫자: 천 단위 쉼표(`4,812`), 비율 차이는 `%p`, 증감은 부호 표기(`+6%p`, `-2%p`)
- 단위는 숫자 바로 뒤(`1,240h`, `142건`, `26분`) 또는 차트 부제(`단위: 천 명 · 2026년 1~8월`)
- 주석은 `※`로 시작, 작은 회색 글씨
- 강조는 굵게(700) + blue 색 한 가지 방식만. 밑줄·형광펜·이모지 금지
- 차트는 계열 하나가 기본, 값 라벨은 막대 위나 옆에 직접 표기, 범례는 2개 이상 계열일 때만
- 그림자·둥근 모서리는 템플릿에 있는 값만 사용 (대시보드 카드 `border-radius: 12px`, 보고서·발표는 각진 모서리)

## 최종 체크리스트

- [ ] 템플릿의 예시 수치·문구가 남아 있지 않다
- [ ] 입력에 없던 수치를 만들지 않았고, 빈 값은 `[확인 필요]`로 표시했다
- [ ] 모든 숫자에 단위·기준 시점이 있고, 외부 수치에 출처가 있다
- [ ] 팔레트 밖 색상, 외부 스크립트, 외부 이미지가 없다 (`check.js` 통과)
- [ ] 결론(요약)이 맨 앞에 있고, 마지막에 다음 조치/건의가 있다
- [ ] 같은 개념은 같은 용어·같은 색으로 표기했다
